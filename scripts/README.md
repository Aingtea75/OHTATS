# Scripts

Folder ini berisi berbagai script utilitas untuk membantu pengembangan dan operasional sistem OHTATS.

## Daftar Script

- install.py → Instalasi awal project
- setup_database.py → Membuat database
- backup_database.py → Backup database
- start_dashboard.py → Menjalankan dashboard
- run_tests.py → Menjalankan seluruh testing
- build_release.py → Persiapan release
