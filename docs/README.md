# OHTATS Documentation

## 1. Pendahuluan

Folder **docs/** berisi dokumentasi penggunaan (User Documentation) untuk platform **OHTATS (Om Hend Trader AI Trading System)**.

Dokumentasi pada folder ini dibuat sebagai panduan bagi pengguna, administrator, maupun developer dalam menginstal, mengonfigurasi, mengoperasikan, dan memelihara sistem OHTATS.

Dokumen pada folder ini berfokus pada **cara menggunakan sistem**, bukan pada desain atau arsitektur internal. Untuk dokumentasi teknis dan blueprint sistem, silakan lihat folder **docs/blueprint/**.

---

# 2. Tujuan

Dokumentasi ini bertujuan untuk:

- Memberikan panduan penggunaan OHTATS secara lengkap.
- Mempermudah proses instalasi dan konfigurasi sistem.
- Menjelaskan cara menghubungkan OHTATS dengan berbagai platform trading.
- Menjadi referensi operasional bagi pengguna dan administrator.
- Mengurangi kesalahan konfigurasi selama implementasi.

---

# 3. Ruang Lingkup

Dokumentasi pada folder ini mencakup:

- Instalasi sistem
- Konfigurasi aplikasi
- Konfigurasi database
- Penggunaan REST API
- Integrasi MetaTrader 4 (MT4)
- Dokumentasi operasional lainnya yang akan ditambahkan pada pengembangan berikutnya.

---

# 4. Struktur Dokumentasi

Folder **docs/** terdiri dari dokumen berikut:

| Dokumen | Deskripsi |
|----------|-----------|
