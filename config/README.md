# Configuration

Folder ini menyimpan seluruh file konfigurasi sistem OHTATS.

## Konfigurasi

- app.yaml
  Konfigurasi aplikasi utama.

- ai.yaml
  Konfigurasi AI Provider.

- database.yaml
  Konfigurasi database.

- dashboard.yaml
  Konfigurasi dashboard.

- mt4.yaml
  Konfigurasi komunikasi MetaTrader 4.

- logging.yaml
  Konfigurasi logging.

Catatan:
Semua file konfigurasi sistem akan ditempatkan pada folder ini.
