## Vision

Membangun platform Artificial Intelligence Trading yang profesional, modular, cepat, aman, dan dapat dikontrol melalui desktop maupun smartphone.

Platform ini dirancang untuk mendukung MetaTrader 4 sebagai tahap awal dan dapat dikembangkan untuk MetaTrader 5, broker lain, maupun berbagai sumber data di masa depan.
